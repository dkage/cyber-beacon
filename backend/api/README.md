# API

Django routes live in `config/urls.py`, with app routes under `/api/v1/`.
`openapi.yaml` is generated by drf-spectacular. The frontend generates TypeScript
contracts from it with `bun run generate:api`. Authentication follows allauth's
separate `/_allauth/browser/v1/` contract.

See [the release contract](../../docs/phase-one-contract.md) and
[Django conventions](../../docs/agents/django.md) before changing behavior.
