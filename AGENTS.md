# AGENTS.md

This project has many different agents that work on it. As each use its own unique approach for "md" initial prompt, the
whole agents instructions will be centralized in `./CLAUDE.md`.

Consider `./CLAUDE.md` as the main source of truth for all agents' instructions and guidelines. Each agent may have
specific configurations, capabilities, and limitations that are detailed in this file.

When contributing to the project or interacting with the agents, please refer to `./CLAUDE.md` for the most up-to-date
information on how to effectively utilize each agent's features. If any updates were to be added to AGENTS.md, add
them to `./CLAUDE.md` instead.

`AGENTS.md` should never be modified.
